# xiaomao-custom-rules

Custom routing rules for xiaomao.

## Doubao

`doubao.txt`

Used to force Doubao traffic through proxy mode in xiaomao.

Current rules (wildcard sub-domain format):

```text
*.doubao.com
*.volces.com
*.volcengine.com
*.bytedance.com
*.bytecdn.cn
*.pstatp.com
*.snssdk.com
*.toutiao.com
*.ixigua.com
*.zijieapi.com
```
